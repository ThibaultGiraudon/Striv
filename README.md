# Striv 🏃‍♂️
**Work in progress**

Striv is an iOS running app built with **SwiftUI**, focused on running analytics
and performance insights.

## 🚧 Status
This project is currently under active development.

## ✨ Features (in progress)
- Running analytics and activity tracking
- HealthKit integration
- Weekly & monthly volume analysis
- Interactive charts and data visualization
- AI-powered insights using Gemini

## 🛠 Tech stack
- Swift, SwiftUI
- MVVM architecture
- async/await
- HealthKit
- CoreData
- Gemini API
